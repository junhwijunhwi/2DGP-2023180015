# 소닉 애니메이션 뷰어 PRD

## 1. 개요

`pico2d`로 소닉 스프라이트 시트에 포함된 동작을 차례대로 보여주는 자동 재생 뷰어를 만든다. 사용자는 프로그램을 실행하는 것만으로 각 동작을 크게 볼 수 있어야 한다.

| 항목      | 내용                                                     |
| --------- | -------------------------------------------------------- |
| 실행 파일 | `Labs/LEC 09/sonic_animation_viwer.py`                 |
| 이미지    | `Labs/LEC08_Animation/sonic-sprite.png` (399×525픽셀) |
| 실행 환경 | Python,`pico2d`                                        |
| 실행 예시 | `python "Labs/LEC 09/sonic_animation_viwer.py"`        |

실행 코드는 위 Python 파일 하나에 작성한다. 이미지 경로는 현재 작업 폴더가 달라도 찾을 수 있도록 스크립트 위치를 기준으로 계산한다.

## 2. 기능 요구사항

### 스프라이트와 동작 구성

- 시트를 살펴 소닉의 동작별 프레임을 목록으로 정의한다. 달리기·점프·회전/공 형태 등 시트에 있는 동작 시퀀스를 빠짐없이 포함한다.
- 각 동작은 이름, 재생 순서, 프레임별 잘라낼 영역 `(x, y, 너비, 높이)`, 프레임 재생 간격을 가진다. 크기가 다른 프레임도 각각의 영역을 지정한다.
- 제목, 크레딧, 장식 및 소닉 동작과 무관한 그림은 애니메이션 프레임에서 제외한다. 잘라낸 프레임에 이웃 그림이 섞이지 않도록 한다.

### 재생 규칙

1. 첫 동작의 첫 프레임에서 자동 재생을 시작한다.
2. 한 동작의 모든 프레임을 순서대로 **5회** 재생한다. 반복 횟수는 전체 프레임 순회가 끝났을 때만 증가한다.
3. 5회 재생 후 마지막 프레임을 보여준 채 **1초** 대기하고 다음 동작의 첫 프레임으로 넘어간다.
4. 마지막 동작도 같은 방식으로 재생·대기한 뒤 첫 동작으로 돌아간다. 사용자가 종료할 때까지 이 순환을 계속한다.

프레임 전환과 1초 대기는 실제 경과 시간을 기준으로 처리하여 컴퓨터 성능에 따라 재생 속도가 크게 달라지지 않게 한다.

### 화면과 종료

- 캐릭터를 화면 중앙 부근에 원본 프레임의 가로·세로 각각 **4배**로 확대한다. 원본 픽셀의 비율을 유지하고, 어느 동작도 화면 밖으로 잘리지 않게 한다.
- 프레임마다 캐릭터의 위치가 크게 흔들리지 않도록 발 위치 또는 몸통 중심을 기준으로 정렬한다.
- 픽셀 아트가 흐려지지 않도록 확대 방식을 설정한다.
- 창 닫기 또는 `Esc` 입력 시 재생을 끝내고 창을 정상적으로 닫는다.

## 3. 구현 구조

- **프레임 데이터:** 시트의 동작 순서와 자르기 영역을 한곳에 정의한다. 필요하면 동작마다 프레임 간격을 따로 지정한다.
- **재생 상태:** 현재 동작, 현재 프레임, 완료한 반복 횟수, 대기 여부와 경과 시간을 관리한다.
- **메인 루프:** 입력 처리 → 경과 시간으로 상태 갱신 → 캔버스 지우기·프레임 그리기 → 화면 갱신 순서로 동작한다.
- **좌표 처리:** 시트에서 측정한 프레임 좌표를 `pico2d`의 이미지 자르기 좌표계에 맞춰 변환한다. 모든 영역이 이미지 경계 안에 있는지 확인한다.
- **리소스 처리:** 시작할 때 이미지를 한 번 로드한다. 파일이 없거나 로드에 실패하면 원인을 알 수 있는 오류를 출력하고 종료한다.

## 4. 단계별 개발 계획

각 단계의 결과를 확인한 뒤 다음 단계로 진행한다. 단계별 변경을 나누어 **20개 이상의 커밋**을 남기며, **모든 커밋 메시지는 한글로 작성한다.**

| 단계 | 구현 내용 | 확인할 결과 |
| --- | --- | --- |
| 1 | 단일 실행 파일과 프로그램 진입점 작성 | 스크립트가 실행됨 |
| 2 | `pico2d` 캔버스 열기·닫기 | 빈 창이 정상적으로 열리고 닫힘 |
| 3 | 창 닫기와 `Esc` 입력 처리 | 두 방법으로 오류 없이 종료됨 |
| 4 | 스크립트 기준 이미지 경로 계산 | 작업 폴더가 달라도 파일을 찾음 |
| 5 | 이미지 로드 및 실패 시 오류 처리 | 파일이 없으면 원인을 출력하고 종료함 |
| 6 | 시트의 소닉 동작 시퀀스와 재생 순서 조사 | 포함할 모든 동작이 목록화됨 |
| 7 | 동작·프레임의 좌표와 재생 간격을 담을 데이터 정의 | 크기가 다른 프레임도 표현 가능함 |
| 8 | 첫 동작의 프레임 좌표 기록 | 첫 동작의 모든 프레임 영역이 지정됨 |
| 9 | 나머지 동작의 프레임 좌표 기록 | 소닉 동작의 프레임이 빠짐없이 지정됨 |
| 10 | 프레임 좌표의 이미지 경계 검사 | 잘못된 좌표를 실행 전에 발견함 |
| 11 | 지정한 프레임 자르기·그리기 | 이웃 그림 없이 한 프레임이 표시됨 |
| 12 | 실제 경과 시간 측정 | 매 반복마다 경과 시간을 계산함 |
| 13 | 프레임 간격에 따른 다음 프레임 전환 | 한 동작이 순서대로 재생됨 |
| 14 | 동작 끝에서 반복 횟수 계산·초기화 | 전체 프레임 순회가 1회로 계산됨 |
| 15 | 5회 반복 후 대기 상태 진입 | 다섯 번째 순회 전에는 넘어가지 않음 |
| 16 | 마지막 프레임을 유지하며 1초 대기 | 대기 중 그림이 유지되고 전환 시점이 맞음 |
| 17 | 다음 동작으로 전환 | 새 동작이 첫 프레임부터 재생됨 |
| 18 | 마지막 동작에서 첫 동작으로 순환 | 전체 목록이 무한 반복됨 |
| 19 | 4배 확대·정렬·선명도 조정 | 모든 동작이 잘리지 않고 선명하게 보임 |
| 20 | 전체 재생, 실행 경로, 종료 동작 검수 | 완료 기준의 모든 항목을 충족함 |

## 5. 완료 기준

- 스프라이트 시트의 소닉 동작 시퀀스가 누락 없이 목록화되고 모두 재생된다.
- 각 동작의 프레임 순회가 정확히 5회 끝난 뒤 1초 대기한다. 마지막 동작 후에도 첫 동작부터 계속 재생된다.
- 모든 프레임의 잘라내기 영역과 위치가 올바르며, 캐릭터가 4배 크기로 선명하고 잘리지 않게 보인다.
- 프로젝트 루트 등 다른 작업 폴더에서 실행해도 이미지가 로드되고, 창 닫기와 `Esc`로 오류 없이 종료된다.
